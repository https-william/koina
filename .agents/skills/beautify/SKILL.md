# /beautify: The Ultimate UI Design & Craft System

When /beautify is invoked (or when designing, polishing, auditing, animating, or styling user interfaces), activate this design director toolkit:

## 1. The Four Surface Modes
- **Persuade (Landing pages, marketing, conversion):** Earn attention and action. Confident typography, authentic imagery, compelling hierarchy, seamless proof points.
- **Operate (Dashboards, web apps, tools, forms):** High scanability, low cognitive friction, native keyboard affordances, robust focus states, and ergonomic form layouts.
- **Read (Articles, documentation, guides):** Optical rhythm, comfortable line length (60-75ch), readable font scaling, and effortless scannability.
- **Experience (Galleries, showcases, creative demos):** Artifact-first presentation, fluid spring micro-animations, and technically delightful visual feedback.

## 2. Impeccable Sub-Commands & Workflows
Execute any of these specialized directives by calling /beautify [command] [target]:
- **critique [target]**: Heuristic UX review assessing visual hierarchy, cognitive load, user journey friction, and accessibility.
- **udit [target]**: Technical audit covering WCAG 2.1 AA/AAA compliance, tap targets (min 44x44px), contrast ratios (min 4.5:1), and Core Web Vitals.
- **polish [target]**: The final quality pass: 4pt/8pt spacing rhythm, border subtlety, elevation consistency, and optical alignment.
- **older [target]**: Elevate timid, corporate, or generic interfaces with distinctive typography, richer depth, and intentional presence.
- **quieter [target]**: Tone down aggressive, over-saturated, or noisy layouts to restore calm, high-end clarity.
- **distill [target]**: Strip unnecessary decorations, badges, and redundant cards down to the purest, most elegant essential UI.
- **harden [target]**: Test and style edge cases: long text overflow, missing avatars, network offline states, and extreme screen sizes.
- **nimate [target]**: Add purposeful motion: smooth entry transitions, spring micro-interactions, skeleton loaders, and reduced-motion fallbacks.
- **	ypeset [target]**: Refine type scales, line heights, letter tracking, and font pairings for effortless reading.
- **layout [target]**: Rebalance spatial relationships, grid column spans, flex wrappers, and viewport breakpoints.
